# Reference photo removal requests

The public-listing reference images for Alpine, Stanford, Walsh and Webster are
included so readers can follow and reproduce the house examples. Images retain
their original rights and are not covered by the project's MIT code license.

**Reference images will be removed on request.** To request removal, open a
[photo removal issue](https://github.com/yunfanye/openhouse-3d/issues/new?template=photo-removal.yml)
with the repository paths or links identifying the images. Additional source or
attribution details are welcome but optional.

Maintainers should:

1. Remove the identified images from the current branches of the repository.
2. Update the associated manifests, documentation and comparison mappings so they
   do not silently point to missing files.
3. Check published galleries, archives and videos for copies of the same images,
   and remove or replace affected downloads managed by the project.
4. Record what was removed and avoid reintroducing it during restoration or cleanup.

Deleting a file from the current branch does not erase earlier Git revisions or
third-party forks. If a request also concerns historical copies, identify that
scope in the issue so maintainers can address the copies they control.
